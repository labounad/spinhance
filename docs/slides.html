Stage 2 · parameter estimation

Chemically realistic δ and J assignment via substructure matching — without experimental measurement.

Training requires only that spin systems are chemically and physically plausible. The model learns the inverse Hamiltonian map from the distribution of realistic parameters.

  • δ and J (²J, ³J, ⁴J) by substructure matching against curated reference tables.
  • Karplus equation for ³J with dihedral angles from 3D embedding.
  • Gaussian perturbation introduces diversity, prevents memorization of discrete values.

Stage 3 · spectral simulation

Exact ¹H spectra from spin Hamiltonian diagonalization via spin-cluster decomposition.

H  =  Σi σi Iz,i  +  Σi<j Jij Ii·Ij
Zeeman — field & shifts σicoupling — spin–spin Jij
  • Observed transitions correspond to allowed eigenvalue differences; selection rules (Δm = ±1) define the stick spectrum.
  • Stick spectrum convolved with a fixed-width Lorentzian lineshape to reproduce instrumental broadening.
  • Full diagonalization scales as 2N — pyspin uses spin-cluster decomposition → linear scaling at near-exact accuracy.

Model · graph-structured decoder

The spin system is a molecular graph; the architecture is designed to predict one.

16,384 pts

convolutional stem → ppm-indexed feature tokens

ENCODER

self-attention

▶
DECODER

8 learned queries

one query per spin group cross-attends spectral tokens (DETR-style set prediction)

▶
OUTPUT HEADS

nodes + edges

δ and multiplicity per node; symmetric J and coupling presence per pair

Each spin-group query learns to attend the spectral regions corresponding to its multiplet; a symmetric edge head predicts all 28 couplings jointly, encoding the unordered graph structure by construction. (Support-region tokenization was evaluated but yielded no improvement over global attention.)

Sam. The key idea: an unordered graph (8 nodes, 28 edges) deserves a structured decoder, not a flat regressor. Encoder = self-attention over conv tokens (ppm-positioned). Decoder = 8 learned spin-group QUERIES cross-attend the spectrum (DETR-style set prediction). Heads = node (δ, n) + symmetric edge (J, presence). Result: shift 7.5× better (0.037 ppm), J 0.59 Hz, F1 0.94, deg 0.95. Support-region tokens were tested but added nothing — dropped.
Model · architectural refinements

Two targeted modifications address residual failure modes; generalization confirmed on held-out data.

  • Peak-channel augmentation: the spectrum is supplemented with a peak-picked intensity channel to improve chemical shift localization.
  • Soft-equivalence edge label: a learnable binary edge label identifies accidentally degenerate spin groups (shared δ, distinct J). When flagged, shifts are averaged at rendering — eliminating spurious doublet artifacts from near-degenerate pairs.
  • Both modifications are incorporated in the production checkpoints; shift MAE is unchanged, and the rendering artifact is resolved.
Generalization: accuracy on the held-out test split is statistically indistinguishable from validation performance — no evidence of overfitting.

Scale-up & future directions

Scaling to 3.1M PubChem systems; a classifier-gated ensemble generalizes beyond fixed spin-group cardinality.

Current status
  • All reported models were trained and benchmarked on the 64k ChEMBL 8-spin-group corpus.
  • The data pipeline has been extended to 3.1M PubChem 8-spin-group systems with associated simulated spectra.

Path to generality
  • Train a suite of fixed-N models (N = 2–12 spin groups) on PubChem-derived data.
  • Train a spin-group classifier to infer N directly from the observed spectrum.
  • Compose classifier + fixed-N decoder → spin-system inversion for arbitrary small molecules at any field strength.

Conclusions

Second-order benchtop spectra contain sufficient information for quantitative spin-system recovery.

  • Deliverables: an open-source, linearly-scaling spin simulator (pyspin, 1,500 spectra/s), a 3.1M-compound training corpus, and a graph-structured transformer decoder recovering chemical shifts to 0.037 ppm MAE and scalar couplings to 0.59 Hz MAE.
  • Key findings: low-field second-order spectra preserve the full spin-system parameter set; graph-structured prediction outperforms flat regression by 7.5× on shifts; chemically plausible synthetic training data is sufficient for generalization.
  • Significance: quantitative ¹H structural characterization from a permanent-magnet benchtop instrument — enabling in-situ, continuous reaction monitoring without access to a high-field facility.
